# carweb-backend

Backend API for the car website with database models, authentication, and route handlers for user and vehicle operations.

## Tech Stack

- Node.js, Express, MongoDB, JWT

## Features

- RESTful APIs
- Authentication
- MongoDB models
- Protected routes
- User management

## Getting Started

1. Open a terminal in the project folder.
2. Install dependencies:
   cd carweb-backend
   npm install
3. Start the app:
   npm run dev

## Run the Application

Open the app in your browser:

- http://localhost:5000

## Environment Variables

Create a .env file in the project root if needed with values like:

PORT=5000
MONGO_URI=mongodb://localhost:27017/your-db-name
JWT_SECRET=your-secret-key

## Notes

- Keep secrets and credentials in .env.
- Use separate branches for features and fixes.
