# car-web

A premium car selling and browsing website featuring listings, modern landing pages, and a sleek UI designed for vehicle discovery.

## Tech Stack

- React, Vite, Tailwind CSS

## Features

- Car listing page
- Modern catalog UI
- Responsive design
- Search-friendly layout
- Dealership style frontend

## Getting Started

1. Open a terminal in the project folder.
2. Install dependencies:
   cd car-web
   npm install
3. Start the app:
   npm run dev

## Run the Application

Open the app in your browser:

- http://localhost:5173

## Environment Variables

Create a .env file in the project root if needed with values like:

PORT=5000
MONGO_URI=mongodb://localhost:27017/your-db-name
JWT_SECRET=your-secret-key

## Notes

- Keep secrets and credentials in .env.
- Use separate branches for features and fixes.
